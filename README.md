# Daily-Task-Conqueror
Help you break up your daily goals into more manageable task.

##Description
A simple web app built with HTML, CSS, and JavaScript to help users break down their main goals into smaller task. Also gives the option of how high or low their energy level is. Current working feature is the light to dark mode.
